# 브레인스토밍 기록

결론이 난 항목만 적는다. 열린 질문은 맨 아래 "열린 질문"에 둔다.

## 2026-10-27 — 시작

- **콘셉트: 플레이어가 AI를 연결하는 전쟁 시뮬레이션.** 플레이어는 프롬프트를 직접 쓰지 못하고, 게임이 주는 세팅으로만 AI를 조율한다. 요청은 정해진 횟수만 나간다. → "누가 AI를 더 잘 쓰느냐"(세팅)와 모델 자체의 성능이 경쟁력이다.
- **게임 행동: 거점 발전, 공격·방어, 외교 등.** 게임이 제공하는 에이전트가 수행한다.
- **가제: `proxywar`(대리전).** 마스터 대신 AI가 싸운다는 뜻. 정식 이름은 나중에.
- **개발자는 플랫폼만 제공한다. AI는 플레이어가 자기 계정으로 연결한다.** API 건당 과금은 부담이 커서 **개인 구독으로 연결되기를 원한다.**
  - 2026-10 조사(2차 보도 중심, 공식 문서로 재확인 필요): OpenAI는 "Sign in with ChatGPT"로 Plus·Pro 구독 사용량을 외부 앱에서 쓰게 허용했다(2026-09 DevDay, 출시 파트너 16곳, 앱별 주간 상한 설정 가능, ChatGPT·Codex와 같은 한도를 나눠 씀). **일반 개발자가 붙일 수 있는지, 파트너 신청이 필요한지는 미확인.** Anthropic(Claude Pro/Max)은 외부 앱이 구독 자격으로 요청을 보내는 것을 금지하고 2026-01부터 차단 중이다. Google(AI Pro/Ultra)은 Gemini CLI OAuth를 외부에서 쓰면 약관 위반이다. 그 밖의 경로는 API 키와 로컬 모델.
  - → 호출량이 예측 가능해야 구독 한도 안에서 플레이할 수 있다. 아래 영웅 구조 결정의 주된 근거다.
- **AI 호출 주체: 서버.** 플레이어 PC가 꺼져 있어도 턴이 돈다. → 플레이어의 키·토큰을 서버가 보관하므로 보안 설계가 필요하다.
- **밸런스: 특정 모델이 우세하면 개발자가 개입해 조정한다.** 수단은 미정(열린 질문).
- **세팅: 다양하고 복잡하게. 다만 값은 boolean이나 1~5 점수.** 프롬프트 작성 수준까지는 가지 않는다. → 게임이 세팅값으로 프롬프트를 조립하므로, 조립 템플릿 자체가 밸런스의 핵심이 된다.
- **턴(잠정): 서버 시계로 30분이나 1시간마다 한 번 진행하고, 턴 시작 약 5분 전에 입력을 마감한다.** 사용자가 아직 깊게 정하지 않았다. → LLM 응답 지연은 문제가 되지 않는다.
- **외교: 정형 제안만**(동맹·불가침·자원 교환 같은 정해진 제안 타입). 자연어 메시지는 없다. → 상대 AI의 메시지로 내 AI를 속이는 프롬프트 인젝션이 구조적으로 생기지 않는다.
- **플레이어 역할: 감독형이 기본.** 직접 개입도 할 수 있고, 사람이 AI와 직접 겨룰 수도 있으며, AI를 연결하지 않고도 플레이할 수 있다. → 사람과 AI가 같은 행동 목록을 쓰는 구조가 자연스럽다.
- **영웅: 플레이어는 마스터이고, 마스터당 영웅 N명을 보유·육성한다.**
- **영웅 구조: 중간관리자(가칭 "참모")만 AI다.** 턴마다 한 번 호출되어 영웅별 임무를 정한다. 영웅은 AI가 아니라 능력치·특성(1~5, boolean)으로 임무의 수행 결과가 달라지는 규칙 기반 실행자다(예: 충성이 낮으면 가끔 명령을 어긴다). 영웅마다 AI를 두는 안은 기각했다. 호출량이 영웅 수에 비례해 구독 한도를 빨리 소진하고(30분 턴·영웅 5명이면 하루 240회 대 48회), 영웅끼리 협조하기도 어렵다.

## 2026-10-27 — 게임 규칙 설계

설계서: `docs/superpowers/specs/2026-10-27-game-rules-design.md`. 아래는 그 결정의 요약이다.

- **매치: 마스터 6명, 1시간 턴 × 5일(120턴).** 위의 "턴(잠정)"을 확정·대체한다. 최소 사람 1명이면 열리고, 빈자리는 저가 모델 봇(운영자 비용 부담, 세팅 프리셋별 성격)이 채운다. → "개발자는 플랫폼만 제공"의 예외는 봇 호출 비용뿐이다.
- **승리: 거점 과반 12턴 연속 보유로 조기 승리, 아니면 120턴 뒤 점수 순위. 단독 승리만.** 거점 0개면 탈락, 수도 함락 시 수도 이전.
- **턴 흐름: 정각 처리 직후 참모 정기 호출(턴당 1회) → 약 55분 검토(직접 수정, 세팅 변경 후 수동 재계획) → 5분 전 마감.** 수동 재계획은 하루 3회(이월 없음). 실패한 호출은 재시도하지 않고 규칙 참모로 대체한다. → 마스터당 매치 최대 135회. 자동 긴급 호출은 기각했다(상시 명령과 겹치고 턴 처리가 복잡해진다).
- **규칙 참모: LLM 없이 세팅값대로 계획.** AI 미연결 마스터, 호출 실패, 기준선 측정에 쓴다.
- **맵: 거점 30개 안팎의 노드 그래프. 자원: 금·식량·자재 + 희귀 1종. 군사: 영웅이 병력을 이끈다. 시야: 전장의 안개.**
- **세팅 5종: 성향(1~5), 지침(boolean, 강제 없음), 안전장치(소수, 게임이 강제), 정보 구성(on/off + 상세도, 보고서 길이 예산 안), 영웅별 상시 명령.** 성향·지침·안전장치·상시 명령은 자유롭게 정하고, 제약은 정보 구성의 길이 예산뿐이다.
- **보고서 길이 예산은 매치 안 정보 건물로만 늘어난다.** 영웅 등급·과금과 분리한다.
- **AI 지휘관 장치: 참모 메모(턴 간 기억), 조건부 명령(턴 처리 중 반응, 추가 호출 없음), 전쟁 일지(상대 것은 매치 후 공개), 강제 규칙 최소화.**
- **명령 확정 순서: 마스터 직접 수정 > 제약(상시 명령 + 안전장치, 함께 적용) > 참모 계획.**
- **외교: 정형 제안 6종(불가침·동맹·자원 교환·포로 교환·선전포고·파기). 배신은 벌칙 없이 허용하고, 약속 기록을 공개한다.**
- **영웅 명부는 계정에 남고, 레벨·능력치 성장은 매치마다 새로 시작한다. 매치마다 명부에서 5명 출전.**
- **등급: 1~5성(별 개수), BM의 축.** 레벨당 상승폭은 획득 등급 기준으로 평생 유지된다. 6~7성은 특수한 조건에서만 승급한다(조건 미정).
- **유대: 출전 기록과 매치 밖 훈련(주간 상한)으로 쌓이고, 차면 승급할 수 있다.** pay-to-win을 막는 장치다.
- **아웃라이어: 등급보다 높은 숨은 성장 계수. 낮은 등급일수록 확률이 높고, 성장으로 추정하다가 첫 승급 때 공개된다.**
- **영웅 패배는 매치 안 부상·포로뿐이다.** 명부와 유대에는 영향이 없다.
- **직접 플레이: 매치 안 탐험(하루 2회, 영웅 3턴 이탈, 결과는 참모가 쓸 정보·자원), 매치 밖 영웅 훈련(하루 3회).** 마스터가 직접 할 때만 일어나고 하루 상한이 있다. 미니게임은 기록만 하고 밸런스를 잡은 뒤 결정한다.
- **모델 밸런스: 지원 모델 목록제 + 모델별 보고서 예산 계수 + 매치 기록.** AI 운용에 닿는 것(예산·호출 횟수·세팅)은 팔지 않는다.
- **검증: 빠른 턴 모드(봇 6명으로 매치를 연속 처리)를 첫 구현 범위에 넣는다.** 가설 A~E는 설계서 8절.
- **개발 테스트의 LLM 호출은 사용자 본인의 Claude 구독(`claude -p` 헤드리스)으로 한다.** 테스트 전용이고, 출시 후 플레이어 연동이나 운영 봇과는 별개다. 2차 자료 기준으로 본인 PC의 개인적인 스크립트 사용은 허용으로 보이지만, 공식 문구는 미확인이다. → 구독 한도 때문에 대량 연속 측정은 막힐 수 있다. LLM 호출부를 교체 가능하게 두고, 초기 테스트는 LLM 참모 수나 턴 수를 줄여 돌린다(S1 설계에서 확정).

## 열린 질문

- 미니게임 도입 여부(전체 밸런스를 잡은 뒤).
- 6~7성 승급 조건.
- BM 상세(무엇을 어떻게 파는가), 같은 매치 안 등급 격차의 허용 범위.
- 자동 긴급 호출 재도입 여부(조건부 명령으로 부족할 때), 기만 행동.
- 특수 상황(결투·협상)에서만 영웅에게 AI 요청을 쓰는 변형: 나중 확장 후보.
- 구독 연동 경로 확정: OpenAI "Sign in with ChatGPT"의 파트너 조건, API 키·로컬 모델 지원 범위, 봇용 저가 모델 단가.
- 기술 설계: 클라이언트 플랫폼(웹·PC 등)과 서버 구성.
- 수치 표: 전투 공식, 생산량, 경험치 곡선, 점수 공식, 등급별 상승폭.
