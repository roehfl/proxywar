요약

규칙 참모 6명이 맵 ring6에서 매치를 결정적으로 끝까지 돌고, npm run sim -- run <설정>이 match.json과 report.md를 남기는 코어 뼈대를 만들었습니다.

순수 TypeScript 코어(packages/core)가 상태·명령 검증·턴 처리(이동 → 전투 → 생산·모집·유지비 → 승리·탈락)와 규칙 참모를 맡고, packages/sim이 실행 설정·매치 실행기·보고서·CLI를 맡습니다.

실행 중 리뷰로 전투 버그 1건과 규칙 참모의 정체·왕복 문제를 고쳤고, 모집 상한은 사용자 결정으로 "현재 수도 기준"이 됐습니다. 시드 1·2·3 매치는 74~84턴에 서로 다른 승자로 조기 승리로 끝납니다.
